# number5alive OS

DRAFT — internal working copy, 2026-11-05. Not publication copy; public
text ships only with Dan's approval (PLAN.md, Phase 7).

An operating system whose entire surface is one prompt window, with a
local AI system and a cloud AI system behind it, joined by a governed
record and returning one combined view: both generations, whole and
labelled, for the human to decide on.

Why two systems behind the window, and not one bigger one? A single
intelligence can't check itself; it can only agree with itself at
higher speed. This OS is built on the opposite bet: different
intelligences, kept different, under one prompt — with the human as
the third node, the one who decides.

- `PLAN.md` — the plan: design law, architecture, gated build order.
- `docs/contracts.md` — Phase 0: the prompt envelope, the return
  envelope, and the seat-adapter contract.

Reference implementation pairing: Johnny 5 (home seat) and Alex on Muse
(cloud seat). First third-party seat occupant: Hermes. Licensing posture
for future releases (ratified 2026-11-04): AGPLv3 core, Apache 2.0 for
separable libraries.
